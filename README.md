# Knowledge Vault

This is an Obsidian vault tracked with Git and GitHub.

## Structure
- `inbox/` - temporary captures
- `sources/papers/` - papers and detailed reading notes
- `sources/papers/_pdf/` - local-only downloaded PDFs, ignored by Git
- `sources/youtube/` - source notes from videos and podcasts
- `concepts/` - evergreen distilled knowledge
- `projects/` - active project notes
- `templates/` - reusable research, paper, synthesis, and publication templates
- `RESEARCH_WORKFLOW.md` - private-research to public-garden workflow
- `VAULT_INDEX.md` - human-readable vault map
- `vault_manifest.json` - machine-readable vault map

## Workflow
1. Define the question in a research brief.
2. Capture papers and evidence in private source notes.
3. Synthesize across sources and update related concepts or projects.
4. Prepare a publication draft and complete its evidence and privacy checks.
5. Promote a self-contained version to the public research garden.
6. Record the published path and URL back in the originating vault note.
7. Refresh `VAULT_INDEX.md` and `vault_manifest.json`.

See [[RESEARCH_WORKFLOW|Research Workflow]] for the full lifecycle and publication contract.
